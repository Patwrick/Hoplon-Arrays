# Changelog

## 0.1.0 — Prepared, not published

First prototype source release for Hoplon-Arrays, an under-desk cable-routing and cable-management system. This version identifies the release snapshot; the mechanical design remains rev7.

- Documented the unchanged canonical 4 × 4 SCAD configuration, eight silicone support fins, four post ribs, separate rigid panel, and three-piece mold.
- Added three regenerated, mesh-checked print candidates and a clearly labeled socketless silicone reference, with provenance manifests.
- Withheld the center-piece STL after detecting zero-area triangles; a complete printable mold set is not included.
- Added the proposed Shore 40A DIY guide, owner-used material links, calculated hardware, parameter inventory and validation limits.
- Added three current-CAD images, a physical-photo/video handoff, and a proposal for future panel-back adhesive-fitting slits.
- Added custom personal/noncommercial licensing, export/inspection/render tools, and an explicit release file list with archive integrity checks.
- Excluded original unmatched STLs, the legacy STEP/quote package, bundled executables, private audit records and Git metadata from the prepared archive. Original local files were preserved.

See [release notes](docs/release-notes.md) for the intended scope and known limitations. No publication date or tag is claimed until the owner authorizes and performs publication.
